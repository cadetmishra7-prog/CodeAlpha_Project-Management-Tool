# 📋 CodeAlpha - Project Management Tool

A modern Project Management Tool built using React.js for the CodeAlpha Internship.

---

## 🚀 Features

✅ Create Projects

✅ Edit Projects

✅ Delete Projects

✅ Add Tasks

✅ Assign Team Members

✅ Task Priority (High, Medium, Low)

✅ Due Date

✅ Kanban Board
- To Do
- In Progress
- Done

✅ Progress Bar

✅ Dashboard Statistics

✅ Search Projects

✅ Dark Mode

✅ Local Storage

✅ Export Projects as JSON

---

## 🛠 Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Local Storage

Clone the repository

```bash

```

Install dependencies

```bash
npm install
```

Start the project

```bash
npm start
```
